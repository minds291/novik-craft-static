# Статическая версия NOVIK

Откройте `index.html` в этой папке двойным щелчком. Страницы, стили, изображения, шрифты и клиентские скрипты находятся в папке и не требуют Astro, установки пакетов или запуска сервера. Сохраняйте структуру папок при переносе сайта.

Снимок сформирован из локальных данных проекта; изменения в Directus автоматически сюда не попадают. Можно также разместить содержимое на статическом хостинге.

Корзина и избранное используют хранилище браузера; его поведение при открытии файлов зависит от браузера. Оформление заказа и форма «Кастомная вещь» показывают демонстрационное подтверждение: данные никуда не отправляются. После оформления корзина очищается.
